# Personal Work page

A responsive, monochrome one-page site with interactive Motivation / Work tabs.

## Preview locally
Open `index.html` in a browser.

## Publish on GitHub Pages
Replace the existing `index.html` in your `my-bio` repository with this file, commit the change, and GitHub Pages will publish it. Keep a copy of your previous file first if you want an easy rollback.

Note: the tools section includes systems named in the conversation and CV. Check the list before publishing to make sure every tool reflects your own experience.
